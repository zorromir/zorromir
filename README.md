# Kelvin Schouten

**MSc Quantitative Finance · BSc Mathematics**

I am a Quantitative Finance master's student at Tilburg University, with a background in mathematics from Utrecht University.

My interests lie in applying mathematical modelling, statistics, and computational methods to financial problems. I enjoy starting with a question, examining the assumptions behind a model, and exploring its behaviour through mathematical analysis and numerical experiments.

This GitHub profile contains selected academic, research, and independent projects.

## Selected projects

**[Pipeline Flow Modelling](https://github.com/zorromir/pipeline-flow-modelling)**
